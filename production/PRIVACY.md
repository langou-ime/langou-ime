# 懒狗输入法隐私基线（v1.0.0）

## 普通输入

RIME 拼音、9 键、英文、数字、符号、Emoji、候选学习在设备本地运行。AI 服务不可用
时不得影响普通输入。

## AI 上下文

客户端优先使用 Android Accessibility 或 Windows UIA 读取聊天文本；可信度不足时
才在本机内存中截图并运行 PP-OCRv6。截图不上传、不落盘，OCR 完成后立即释放。
上送字段只有匿名设备/账号标识、应用类型、语言、脱敏后的聊天轮次、可选草稿和
保存偏好。

密码框、银行/支付、密码管理器、系统安全页和受保护窗口禁止采集。AI 建议只有用户
点选后才写入当前输入框，永不自动发送。

## 账号与保存

游客可输入和使用 AI。手机号登录用于云历史、设置及跨设备同步。聊天文字与生成结果
默认加密保存 30 天；用户可关闭保存或立即清空。后端每天硬删除过期记录。访问令牌
短期有效，刷新令牌轮换并保存于 Android Keystore 或 Windows DPAPI。

## 诊断

公开稳定版匿名诊断默认关闭，用户可主动开启。诊断不得上传聊天正文、截图、手机号、
访问令牌或密钥。

## 用户权利

用户可查询和删除历史、清空全部云数据、关闭保存、退出账号并在卸载时清除本地敏感
数据。正式上线前需补充运营主体、联系邮箱和适用法律要求，并由合格人员审核。
