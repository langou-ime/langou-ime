# 懒狗输入法 Android

简体中文说明已合并到仓库首页：[README.md](README.md)。

懒狗输入法支持 Android 8.0+，以
[Trime v3.3.10](https://github.com/osfans/trime/tree/v3.3.10) 与
[RIME](https://rime.im/) 为离线输入核心。本仓库保留完整上游历史和
GPL-3.0-or-later 许可，并新增三款原创皮肤、本地上下文 OCR、AI 建议、账号和
Ed25519 签名更新。

密码框、银行/支付、密码管理器及系统安全页面一律禁止采集；截图不上传、不落盘。
正式包只从 [langou.tech](https://langou.tech/) 与 `langou-ime/android`
GitHub Release 提供。
