# 懶狗輸入法 Android

完整的專案說明及建置方法請見：[README.md](README.md)。

懶狗輸入法支援 Android 8.0+，以
[Trime v3.3.10](https://github.com/osfans/trime/tree/v3.3.10) 與
[RIME](https://rime.im/) 為離線輸入核心。本儲存庫保留完整上游歷史與
GPL-3.0-or-later 授權，並新增三款原創面板、本機內容 OCR、AI 建議、帳號及
Ed25519 簽章更新。

密碼欄、銀行／支付、密碼管理器及系統安全頁面一律禁止擷取；截圖不上傳、不寫入
磁碟。正式安裝包只從 [langou.tech](https://langou.tech/) 與
`langou-ime/android` GitHub Release 提供。
