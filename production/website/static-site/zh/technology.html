🏗️ 四层架构

每一层都有明确的职责和安全边界

📱
第一层 · 用户设备
Android（Trime客户端 + 无障碍服务）、Windows（UI Automation + 悬浮窗）、iOS/macOS（开发中）。负责屏幕文本采集、输入法引擎、用户交互界面。
Android 8.0+Windows 10+iOS (2027)
👁️
第二层 · 上下文感知引擎
通过无障碍服务（Android）或UI Automation（Windows）读取屏幕上的聊天文本。备用通道：截图 + PaddleOCR本地识别。智能过滤广告和系统通知，只保留有效对话。
最多10条消息内存级处理不写入磁盘
🧠
第三层 · AI推理层
小米MiMo-V2.5-Pro大语言模型，420亿激活参数MoE架构。支持32K上下文窗口，2-3秒端到端延迟。针对聊天场景深度优化的提示工程，生成6种风格的自然回复。
420亿参数32K上下文2-3秒延迟
🔐
第四层 · 安全传输层
HTTPS/TLS 1.3端到端加密传输。对话文本仅在服务器内存中处理，完成后立即释放。不存储原始截图，不采集GPS、通讯录等无关数据。严格遵守PIPL和GDPR。
TLS 1.3零存储PIPL/GDPR

🔬 技术详情

🧠

MiMo大语言模型

小米MiMo-V2.5-Pro，420亿激活参数MoE架构。中文对话理解极为出色，支持32K上下文窗口。针对聊天回复场景进行了深度提示词优化，生成内容自然流畅。

👁️

上下文感知引擎

主通道：Android无障碍服务 / Windows UI Automation，直接读取屏幕聊天文本。备用通道：截图 + PaddleOCR本地识别（不联网）。智能过滤非聊天内容，分析情绪和意图。

⌨️

RIME输入引擎

基于中州韻开源引擎，支持全拼、双拼、简拼、模糊音。百万级中文词库，智能候选排序。用户自造词自动学习并云端同步。

☁️

云端同步架构

增量同步，仅传输变更数据。用户数据加密存储，密钥由密码派生。支持一键导出全部个人数据（JSON格式）。

📖

开源组件

Android客户端基于Trime（GPL-3.0）。RIME引擎（BSD-3-Clause）。PaddleOCR（Apache-2.0）。后端服务当前闭源，未来计划部分开源。
