📱 Android 版安装教程

下载安装包

点击下方按钮下载最新版APK安装包。建议在Wi-Fi环境下下载（约45MB）。

📥 前往下载页

允许安装未知来源应用

由于懒狗输入法暂未上架应用商店，需要手动允许安装：

  • 打开手机「设置」→「安全」→「更多安全设置」
  • 找到「安装未知应用」或「允许安装未知来源应用」
  • 选择你用来打开APK的文件管理器或浏览器，开启权限

不同品牌的手机路径略有差异。华为/荣耀：设置→安全→更多安全设置→安装外部来源应用。小米：设置→隐私保护→特殊权限→安装未知应用。OPPO/vivo：设置→安全→安装未知应用。

安装并启用输入法

点击APK文件完成安装后，需要启用懒狗输入法：

  • 打开「设置」→「系统」→「语言和输入法」
  • 点击「虚拟键盘」→「管理键盘」
  • 找到「懒狗输入法」，打开开关
  • 在弹出的确认对话框中点击「确定」

切换到懒狗输入法

在任意输入框中点击，系统会弹出输入法选择器，选择「懒狗输入法」即可。或者在通知栏中点击输入法切换图标。

你也可以在「设置→语言和输入法」中将懒狗输入法设为默认输入法，这样就不用每次手动切换了。

开启无障碍服务（推荐）

为了让懒狗自动识别聊天上下文，建议开启无障碍服务：

  • 打开懒狗输入法的设置界面（在通知栏点击懒狗图标，或在输入法中长按地球图标）
  • 点击「开启无障碍服务」
  • 系统会跳转到无障碍设置页面，找到「懒狗输入法」并开启
  • 在弹出的权限确认中点击「允许」

无障碍服务是Android的标准辅助功能，不会影响手机性能或安全。懒狗仅用它来读取屏幕上的聊天文本，不会进行任何其他操作。你随时可以在设置中关闭。

🖥️ Windows 版安装教程

检查系统要求

确保你的电脑满足以下要求：

  • 操作系统：Windows 10 21H2 或更高版本 / Windows 11
  • 处理器：x64 架构（目前不支持ARM）
  • 内存：4GB RAM 或以上
  • 依赖：.NET 8 Desktop Runtime（安装时会自动提示下载）

下载并安装

下载MSI安装包后双击运行，按照安装向导完成安装。安装过程中可能需要管理员权限。

📥 前往下载页

添加输入法

安装完成后需要在Windows中添加懒狗输入法：

  • 打开「设置」→「时间和语言」→「语言和区域」
  • 点击中文（简体）旁边的「...」→「语言选项」
  • 在「键盘」部分点击「添加键盘」
  • 找到并选择「懒狗输入法」

配置与使用

在系统托盘（右下角）找到懒狗图标，右键点击进入设置：

  • 登录懒狗账户（与Android版共享数据和设置）
  • 选择AI回复的默认风格偏好
  • 按 Win+空格 切换到懒狗输入法
  • 在任意聊天窗口中，懒狗会自动识别对话并弹出AI建议

Windows版使用UI Automation读取聊天文本，无需额外授权。如果某个应用无法自动识别，可以手动选中文本后按快捷键触发AI建议。

🎯 使用技巧

选择合适的回复风格

不同场景使用不同风格，效果更佳：

  • 甜蜜：适合恋人、亲密朋友的日常聊天
  • 幽默：适合朋友群聊、轻松社交场合
  • 温暖：适合安慰朋友、家人关怀
  • 专业：适合工作沟通、商务邮件
  • 简洁：适合快速回复、游戏场景
  • 随和：适合日常闲聊、普通社交

善用提示词优化器

在与AI工具对话时，提示词的质量直接决定输出质量。懒狗的提示词优化器可以帮你：

  • 把模糊的指令变成结构化的Prompt
  • 自动添加角色定义、输出格式、约束条件
  • 支持针对不同AI模型的优化策略

使用方法：在ChatGPT/DeepSeek的输入框中输入你的原始提示词，懒狗会自动弹出优化建议。点击即可替换。

AI回复建议

所有功能完全免费，不限次数使用：

  • 日常聊天优先使用AI建议，简单回复可以自己打字
  • AI回复建议没有次数限制，放心使用
  • 所有数据在云端实时同步
  • 基础输入功能（拼音/手写/语音）始终可用

自定义词库

懒狗会自动学习你的常用词汇和输入习惯。你也可以手动管理词库：

  • 在设置中进入「词库管理」
  • 添加常用短语、快捷回复
  • 导入/导出自定义词库文件
  • 词库自动同步到所有已登录设备
