🔌 开发者 API

将懒狗输入法的 AI 回复能力集成到你的应用中

📖

API 概览

懒狗输入法提供 RESTful API，供第三方开发者将 AI 回复生成能力集成到自己的应用中。目前 API 处于 Beta 阶段，面向受邀开发者开放。主要功能包括：根据对话上下文生成 AI 回复建议、分析对话情绪和意图、优化提示词。API 采用标准的 HTTP/HTTPS 协议，响应格式为 JSON。

🔑

认证方式

所有 API 请求需要在 Header 中携带 API Key：

Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

API Key 通过开发者后台申请。每个 Key 绑定一个应用标识，用于调用量统计。Beta 期间不限调用次数。

📡

端点列表

方法端点说明
POST/v1/chat/reply生成 AI 回复建议
POST/v1/chat/analyze分析对话情绪和意图
POST/v1/prompt/optimize优化提示词
GET/v1/user/quota查询 API 调用状态
📝

示例代码：生成 AI 回复

// 请求示例
POST /v1/chat/reply
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "context": [
    {"role": "other", "content": "今天好累啊，加班到现在😩"},
    {"role": "me", "content": "辛苦了，还没下班吗？"},
    {"role": "other", "content": "还在公司，估计还要一小时😭"}
  ],
  "style": "warm",
  "max_suggestions": 3,
  "language": "zh-CN"
}

// 响应示例
{
  "success": true,
  "data": {
    "suggestions": [
      "那你别太辛苦了，做完早点回去休息，路上注意安全🥺",
      "心疼死了😢 我帮你点个宵夜送到公司吧，想吃什么？",
      "坚持住！做完这单周末好好犒劳自己💪 需要我陪你聊会儿吗？"
    ],
    "analysis": {
      "emotion": "tired",
      "intent": "venting"
    }
  },
  "request_id": "req_abc123"
}
💡

参数说明

参数类型必填说明
contextarray是对话上下文消息数组，最多 10 条。每条包含 role（other/me）和 content
stylestring否回复风格：sweet/humor/warm/pro/concise/casual。默认 warm
max_suggestionsint否返回建议数量 1-5，默认 3
languagestring否语言：zh-CN/en/ja/ko。默认自动检测
📊

速率限制

  • 免费开发者：每分钟 60 次请求
  • 认证合作伙伴：每分钟 600 次请求
  • 超出限制返回 429 Too Many Requests 错误码
  • 建议实现指数退避（Exponential Backoff）重试策略
