安装教程

  1. 下载安装包：访问官网下载页面，下载 MSI 安装包。
  2. 运行安装：双击 MSI 文件，按照安装向导的提示完成安装。建议选择「为所有用户安装」。
  3. 切换输入法：在任务栏右下角的输入法图标处，或通过快捷键 Win + 空格，选择「懒狗输入法」。
  4. 启用 AI 功能：右键点击懒狗输入法状态栏图标，选择「设置」>「AI 回复」，开启 AI 上下文感知功能。
  5. 登录账户：如需使用云端同步和 AI 数据管理，点击「登录」按钮注册或登录懒狗账户。
🔧

UI Automation 原理

Windows 版使用 Microsoft UI Automation（UIA）框架来读取聊天窗口的内容。UIA 是 Windows 系统内置的辅助技术框架，与 Android 无障碍服务的原理类似。懒狗输入法通过 UIA 获取当前活动窗口的 UI 树，从中提取聊天文本内容。该过程在本地完成，不截图、不上传图像，仅提取文本数据。提取效率极高，CPU 占用几乎为零。

UIA 支持的应用包括：微信桌面版、QQ 桌面版、钉钉、飞书、Slack 桌面版、Discord、Telegram 桌面版、Outlook、以及所有基于 Chromium 的浏览器中的网页聊天界面。

⌨️

快捷键一览

  • 输入法切换：Ctrl + Shift 或 Win + 空格
  • 中英文切换：Shift
  • 全角/半角切换：Shift + 空格
  • 呼出 AI 建议：自动触发（无需手动操作）
  • 选择第 N 条 AI 建议：Alt + 1 / Alt + 2 / Alt + 3
  • 刷新 AI 建议：Alt + R
  • 打开设置：Ctrl + Alt + L
  • 手写面板切换：Ctrl + Alt + H
  • 语音输入：Ctrl + Alt + V

详细快捷键列表请查看 快捷键参考页面。

📋

兼容性

  • 系统要求：Windows 10 1809 及以上版本 / Windows 11
  • 硬件要求：x64 架构，4GB 以上 RAM
  • 支持的应用：微信桌面版、QQ 桌面版、钉钉、飞书、Slack、Discord、Telegram 桌面版、Microsoft Teams、Outlook、Chrome/Edge/Firefox 浏览器内的聊天页面。
  • 注意：由于 Windows 系统限制，UIA 在某些旧版应用中可能无法完整读取聊天内容。此时懒狗会自动降级为截图+OCR 模式（需要管理员权限）。
⚡

优化建议

  • 开机自启：建议在设置中开启「开机自动启动」，确保每次开机懒狗就在后台就绪。
  • 管理员权限：某些需要读取高权限窗口的应用（如 VS Code、某些 IDE），可以右键懒狗输入法快捷方式，选择「以管理员身份运行」以提升兼容性。
  • 禁用冲突快捷键：如果其他软件的快捷键与懒狗冲突，可以在设置中自定义所有快捷键。
  • 多显示器支持：懒狗输入法完整支持多显示器环境，AI 建议栏自动显示在输入框所在的显示器上。
