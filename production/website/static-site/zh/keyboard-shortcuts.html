⌨️ 快捷键参考

Windows 版和 Android 版完整快捷键列表

🖥️ Windows 版快捷键

所有快捷键都可在设置中自定义修改。

快捷键功能说明
Ctrl + Shift切换输入法在已安装的输入法之间切换
Win + Space切换输入法Windows 标准输入法切换方式
Shift中英文切换单次按下切换中/英输入状态
Shift + Space全角/半角切换切换字符全角/半角模式
Ctrl + .中英文标点切换切换中文/英文标点符号
Alt + 1选择第 1 条 AI 建议直接选择并发送第一条 AI 建议
Alt + 2选择第 2 条 AI 建议直接选择并发送第二条 AI 建议
Alt + 3选择第 3 条 AI 建议直接选择并发送第三条 AI 建议
Alt + R刷新 AI 建议重新生成 3 条 AI 回复建议
Ctrl + Alt + L打开设置快速打开懒狗输入法设置面板
Ctrl + Alt + H手写面板开关打开/关闭手写输入面板
Ctrl + Alt + V语音输入开关开始/停止语音输入
Ctrl + Alt + S风格切换在 6 种 AI 回复风格间循环切换
Ctrl + Alt + M发送模式切换切换直接发送/填入模式
Up/Down候选翻页在输入候选词列表中上下翻页
Enter选择候选词确认当前高亮的候选词
Space选择候选词同上（默认行为，可自定义）
Backspace删除上一个字符返回/删除功能
Esc取消输入清空当前输入编码

📱 Android 版快捷键（物理键盘）

连接物理键盘时可用以下快捷键。

快捷键功能说明
Ctrl + Space切换输入法在已安装输入法之间切换
Ctrl + Shift中英文切换切换中/英输入状态
Alt + 1-3选择 AI 建议选择第 1-3 条 AI 建议
Alt + R刷新 AI 建议重新生成 AI 回复建议

📱 Android 版手势操作

手势功能说明
空格键左右滑动中英文切换在空格键上左右滑动快速切换中/英
AI 建议栏上滑查看更多建议上滑展开更多 AI 建议选项
AI 建议栏下滑刷新建议下滑刷新 AI 回复建议
长按空格键语音输入长按空格键激活语音输入（松开停止）
双指滑动键盘高度调节双指上下滑动调节键盘高度
长按键盘按键候选符号长按键盘上的字母键显示候选符号
