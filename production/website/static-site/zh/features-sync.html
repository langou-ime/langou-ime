☁️ 云端同步

多设备无缝切换，数据永不丢失

🔄

同步内容

注册懒狗账户后，以下数据会在所有登录设备间自动同步：

  • 个人词库：你输入的每一个新词、自造词、专业术语，都会自动同步。在手机上造的词，在电脑上直接能用，无需重新学习。
  • 输入习惯：系统会学习你的打字习惯——你常打的短语、常用的人名、偏好的候选排序——并将这些习惯同步到所有设备。
  • 偏好设置：主题选择、回复风格偏好、发送模式、键盘布局、词库开关等所有设置项，一键同步。
  • 快捷短语：你自定义的快捷短语模板，所有设备共享。
  • AI 数据信息：AI 调用数据在云端统计，多设备共享一个账户的数据。

不同步的内容：聊天记录、截图、个人身份信息等隐私数据。云端同步仅限输入法自身的配置和词库数据。

🔐

安全机制

  • 端到端加密：词库和设置数据在上传前先经过 AES-256 加密，服务器也无法读取你的词库内容。加密密钥绑定你的账户密码。
  • HTTPS 传输：所有数据传输使用 TLS 1.3 协议，防止中间人攻击。
  • 服务器隔离：用户数据存储在与 AI 服务独立的数据库中，数据库使用银行级加密（AES-256 静态加密）。
  • 自动备份：云端数据每日自动备份，即使意外删除也可恢复最近 30 天的版本。
  • 设备管理：你可以在设置中查看所有已登录设备，并远程移除不再使用的设备。
📱

多设备体验

手机和电脑之间的切换体验是懒狗输入法的一大亮点：

📱 Android → 💻 Windows

在地铁上用手机微信聊了一半，到家打开电脑登录微信，词库和设置已经同步好了，继续聊无感切换。AI 数据也共享，不用担心两边数据不同步。

💻 Windows → 📱 Android

在公司用电脑设置了新的快捷短语或调整了主题，回家打开手机，设置已经同步好了。一切同步在后台静默完成，不需要手动操作。

⚡

冲突处理

当多台设备同时修改相同设置导致冲突时，懒狗输入法采用「最后写入者胜出（LWW）」策略。具体来说：

  • 设置项冲突：以最后修改时间为准，后修改的覆盖先修改的。
  • 词库冲突：基于操作日志合并——在一台设备上删除的词不会在另一台设备上恢复，两边的新增词都会保留。
  • 同步频率：默认每 5 分钟触发一次自动同步，手动点击「立即同步」可强制同步。
  • 离线使用：无网络时仍可正常使用所有功能（包括 AI 回复，使用本地缓存），联网后自动同步。
📊

设备支持

  • 无限设备：支持无限台设备同时登录，随时随地同步
  • 注意：同一手机更换 SIM 卡或刷机后，重新登录账号即可恢复所有云端数据。
