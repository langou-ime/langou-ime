Welcome to the Langou Community

Langou is more than a product — it's a community of people who believe typing should be smarter, faster, and more human. Whether you're a developer, a power user, a designer, or just someone who loves great tools, there's a place for you here.

💬

Discord Server

Our Discord server is the most active community space. Join thousands of Langou users to:

  • Get help: Troubleshoot issues with setup, features, or customization
  • Share tips: Post your favorite style combinations, prompt tricks, and workflows
  • Give feedback: Share feature requests and report bugs directly to the development team
  • Sneak peeks: Get early access to beta features before public release
  • Theme showcase: Share your custom themes and download others' creations

Join our Discord →

🐙

GitHub Open Source

Langou's Android client, based on Trime (GPL-3.0), is open source. We welcome community contributions:

  • Report issues: Found a bug? File an issue with reproduction steps
  • Submit pull requests: Code contributions, documentation improvements, bug fixes
  • Translate: Help translate Langou into more languages
  • RIME schemas: Contribute custom input schemas and dictionary files
  • Documentation: Improve our developer documentation and user guides

🎨

Theme Gallery

Pro users can create and share custom themes in the Theme Gallery:

  • Create: Design your own theme using the visual editor or by editing theme JSON files
  • Share: Publish your theme to the gallery with screenshots and descriptions
  • Discover: Browse hundreds of community-created themes
  • Feature: The best themes get featured on our homepage and social media

User Forums

Our web forums are a knowledge base of user-curated content:

  • Tips & Tricks: Browse 50+ community-contributed tips (see our curated list)
  • Use Case Library: Real-world examples of Langou in action across different scenarios
  • Style Showcase: Users share custom style configurations and prompt templates
  • Support: Community-powered troubleshooting and solutions

Contributor Program

We run a formal contributor program for active community members:

  • Bug bounty: Rewards for security vulnerability reports and critical bug fixes
  • Content creation: Write blog posts, make tutorials, create video guides
  • Translation: Help localize Langou into your language
  • Beta testing: Early access to features in exchange for detailed feedback
  • Recognition: Top contributors are featured on our website and receive exclusive rewards

Community Guidelines

We maintain a respectful, inclusive community. All participants are expected to follow our code of conduct: be respectful, assume good faith, help others, and keep discussions constructive. Harassment, hate speech, and spam are not tolerated.
