User Guide

From installation to mastery — get started in 5 minutes

📱 Android Installation

Download APK

Download the latest APK (~45MB). Wi-Fi recommended.

📥 Go to Download

Allow Unknown Sources

  • Open Settings → Security → Install unknown apps
  • Select your browser or file manager, enable permission

Path varies by brand. Samsung: Settings→Apps→Special access. Google Pixel: Settings→Apps→Special app access.

Install & Enable

  • Tap the APK to install
  • Go to Settings → System → Languages & input → Virtual keyboard
  • Tap "Manage keyboards" → Enable "Langou IME"

Enable Accessibility (Recommended)

  • Open Langou settings (tap the globe icon or notification bar icon)
  • Tap "Enable Accessibility Service"
  • Find "Langou IME" in accessibility settings and enable it

Accessibility is a standard Android feature. Langou only uses it to read visible chat text — nothing else. You can disable it anytime.

🖥️ Windows Installation

Check Requirements

  • Windows 10 21H2+ or Windows 11
  • x64 processor, 4GB+ RAM
  • .NET 8 Desktop Runtime (auto-prompted during install)

Download & Install

Download MSI, double-click to run. Admin rights may be required.

📥 Go to Download

Add Keyboard

  • Settings → Time & Language → Language & Region
  • Click "..." on Chinese (Simplified) → Language options
  • Under Keyboards, click "Add a keyboard" → Select "Langou IME"

Configure & Use

  • Right-click the Langou icon in system tray for settings
  • Sign in with your Langou account (syncs with Android)
  • Press Win+Space to switch to Langou
  • AI suggestions appear automatically in any chat window
