⌨️ Keyboard Shortcuts

Complete reference for Langou keyboard commands

Windows Global Hotkeys

These shortcuts work system-wide when Langou for Windows is running in the background. All shortcuts are customizable in Settings → Hotkeys.

⌨️

Global Shortcuts

  • Alt+Space: Toggle Langou overlay on/off
  • Alt+1/2/3: Select suggestion 1, 2, or 3 (same as tapping)
  • Alt+Q: Regenerate all three suggestions
  • Ctrl+Shift+L: Switch to next reply style
  • Ctrl+Shift+K: Switch to previous reply style
  • Ctrl+Shift+1-6: Direct style selection (1=Sweet, 2=Humorous, 3=Warm, 4=Professional, 5=Concise, 6=Casual)
  • Ctrl+Shift+P: Open Prompt Optimizer
  • Ctrl+Shift+F: Fill Mode (insert suggestion without sending)
  • Ctrl+Shift+D: Direct Send Mode
  • Ctrl+Shift+O: Toggle OCR mode (UI Automation vs Screenshot)
  • Ctrl+Shift+E: Open Settings
  • Ctrl+Shift+H: Show/hide overlay completely
  • Esc: Close overlay / cancel current operation
📝

Chinese Input Hotkeys (Windows)

When the Langou Chinese IME is active (not just the overlay):

  • Ctrl+Shift: Switch between Chinese and English input mode
  • Shift: Temporary English mode (hold for single character)
  • Ctrl+Period: Cycle through Chinese punctuation styles
  • Ctrl+\`: Open input schema selector
  • Page Up / Page Down: Scroll candidate list up/down
  • Ctrl+P / Ctrl+N: Previous/next candidate page
  • Tab: Expand current candidate for phrase selection
  • Ctrl+Enter: Force submit current input as raw pinyin
  • Shift+Backspace: Clear entire input buffer
📱

Android Keyboard Gestures

While typing on the Android keyboard:

  • Swipe left on suggestion: Regenerate AI suggestions
  • Swipe right on suggestion: Switch to Fill Mode
  • Swipe down on keyboard: Dismiss keyboard
  • Long-press spacebar: Keyboard language/layout switcher
  • Long-press comma: Quick settings menu
  • Two-finger swipe down: Enter one-handed mode
  • Pinch in/out: Adjust keyboard height
  • Long-press backspace: Rapid delete (accelerating speed)
  • Swipe from delete key: Delete by words instead of by characters
⚡

AI Power User Shortcuts

  • Alt+R (Windows) / Long-press refresh (Android): Force re-capture context and regenerate suggestions
  • Alt+T (Windows) / Tap style name (Android): Temporarily override style for next reply only
  • Ctrl+Shift+A (Windows): Toggle AI suggestions on/off (when you want to type without AI)
  • Ctrl+Shift+S (Windows): Save current reply as a custom template
  • Alt+C (Windows): Copy all suggestions to clipboard as a list
🎨

Theme & Customization Shortcuts

  • Ctrl+Shift+T (Windows): Cycle through built-in themes
  • Ctrl+Shift+B (Windows): Toggle between light and dark mode
  • Ctrl+Mouse wheel (Windows): Adjust keyboard transparency
  • Ctrl+Shift+Y (Windows): Reset theme to default

Customizing Shortcuts

All keyboard shortcuts on Windows can be customized in Settings → Hotkeys. Each action has a default binding that you can change. You can also create chord shortcuts (e.g., Ctrl+K, Ctrl+M for a specific action). On Android, gesture shortcuts are configured in Settings → Gestures.

For more productivity tips, see our Tips & Tricks page. Learn about the Windows version to get the most out of desktop shortcuts.
