💡 Tips & Tricks

20+ ways to get the most out of Langou

Master Langou Like a Pro

Langou is packed with features that go beyond the obvious. Whether you're a new user or a seasoned pro, these tips will help you type smarter, faster, and more expressively.

💡 1. Quick Style Switch

Long-press the style indicator in the suggestion bar to cycle through all six styles without opening the style picker. Perfect for when you need to switch tone mid-conversation.

💡 2. Regenerate Specific Suggestions

Not happy with any of the three suggestions? Swipe down on the suggestion bar to regenerate all three. The new set will be based on the same context but approach it from a different angle.

💡 3. Combine Styles (Pro)

In the Pro settings, create a "mixed style" by sliding between two styles. 70% Professional + 30% Warm creates the perfect tone for a boss who's also a mentor. Experiment to find your sweet spots.

💡 4. Dictionary Short Codes

Create abbreviation expansions in your user dictionary. Type "btw" → "By the way!", "omw" → "On my way!", "ttyl" → "Talk to you later!". These sync across devices via Cloud Sync.

💡 5. Privacy Mode App List

Configure specific apps where Langou should never capture context (banking apps, password managers, private notes). Go to Settings → Privacy → Excluded Apps to add them.

💡 6. The Emoji Shortcut

In Chinese pinyin mode, type "hx" (for 好笑) to get relevant emoji suggestions. The emoji dictionary is continuously updated with modern usage patterns.

💡 7. Speed Dial: Favorites

Pin your most-used reply styles to the top of the style picker. Go to Styles → Favorites and reorder. Your top 3 favorites show as quick-access buttons on the main suggestion bar.

💡 8. Prompt Template Library

Save frequently used Prompt Optimizer templates. Create templates like "Weekly Status Update," "Client Follow-up Email," or "Bug Report" with your preferred structure and constraints.

💡 9. Double Pinyin Mastery

If you're considering switching to double pinyin for speed, start with the Xiaohe (小鹤) scheme. It has the most logical key mapping and a large community of users for support.

💡 10. Context Preview

Tap the context indicator (📋 icon) to see exactly what Langou captured before generating suggestions. This helps you understand why the AI suggested what it did — and spot any capture errors.

💡 11. Night Mode Auto-Switch

Set your keyboard to automatically switch to Dark Mode at sunset and back to your preferred theme at sunrise. Settings → Theme → Auto Theme → Schedule.

💡 12. Temporary Style Override

While typing in one style, press and hold the style name to temporarily switch. Release to revert. This is great for dropping in a professional sentence in the middle of a casual conversation.

💡 13. Voice + Handwriting Combo

You can switch between pinyin, handwriting, and voice input without closing the keyboard. Tap the input mode icon (🌐) to cycle through available modes. Great for typing characters you can't easily pinyin.

💡 14. Keyboard Layouts

Beyond QWERTY and 9-key, try the 26-key layout for double pinyin or the 14-key layout optimized for landscape mode. Available in Settings → Keyboard → Layout.

💡 15. Clipboard History

Long-press the clipboard icon to access your clipboard history. Langou keeps the last 20 items. Frequently used items can be pinned. The clipboard is encrypted and never leaves your device.

💡 16. Custom Sound Profiles

Create sound profiles that change based on time of day. A silent profile from 10 PM to 7 AM, a mechanical click profile during work hours, and a soft tap profile for evenings.

💡 17. Bulk Dictionary Import

Have a list of domain-specific terms? Create a text file with one word per line and import it via Settings → Dictionary → Import. Supports .txt, .csv, and .dict.yaml formats.

💡 18. Offline Mode Basics

Even without internet, Langou works as a full Chinese input method with pinyin, handwriting, and offline voice recognition. Only AI reply generation requires a connection. Your Chinese Input Engine is fully offline-capable.

💡 19. Performance Mode

On older devices, enable Performance Mode in Settings → System. This reduces animations, simplifies the theme, and prioritizes typing speed over visual effects.

💡 20. Report Better AI Suggestions

When an AI suggestion isn't quite right, tap the thumbs-down button and optionally add a brief note. This feedback, combined with the context, helps improve future suggestions — without storing your conversation data.

💡 21. One-Handed Mode

In the keyboard settings, enable One-Handed Mode to shrink and shift the keyboard to the left or right side of the screen. This is extremely useful on large phones and tablets.

💡 22. Haptic Feedback Customization

Fine-tune haptic feedback intensity independently for key presses, suggestion taps, and mode switches. Different feedback patterns help you confirm actions without looking at the screen.

Master the basics first with our Features overview. For desktop-specific shortcuts, see Keyboard Shortcuts. Community tips are shared on our Discord.
