Full-featured system keyboard for Android

Langou on Android: Your System Keyboard

The Android version of Langou is built on the foundation of Trime (同文输入法), a powerful open-source keyboard project. Langou extends Trime with AI capabilities while maintaining full compatibility with the Android keyboard ecosystem. It replaces your default system keyboard, giving you AI-powered suggestions in every app.

⌨️

System Keyboard Integration

Langou registers as a standard Android Input Method Editor (IME). This means:

  • Works everywhere: WhatsApp, WeChat, Telegram, Messenger, Discord, Slack, email apps, browsers — any app with a text input field
  • Google compatibility: Works alongside Google Voice Typing, Gboard clipboard, and other Android input features
  • Edge-to-edge: Supports modern Android edge-to-edge display with proper insets handling
  • Gesture typing: Full swipe-to-type support (Glide Typing) on supported keyboards
  • Split keyboard: Tablet and foldable device support with split keyboard layout
♿

Accessibility Service

To read chat context for AI suggestions, Langou uses Android's Accessibility Service. This is how it works:

  • Read-only: The service only reads text visible on screen — it cannot modify or interact with other apps
  • Context-aware: Only triggers when the Langou keyboard is active and a chat input field is detected
  • Privacy filter: Configurable to exclude certain apps from context capture
  • Transparent: The context viewer (in settings) shows exactly what data was captured
  • Revocable: Can be disabled at any time, though AI suggestions will be less contextually relevant
🧠

On-Device AI Processing

Android devices benefit from significant on-device processing:

  • OCR Engine: PaddleOCR runs entirely on-device using the GPU (via NNAPI/OpenCL). No screenshots are sent to servers.
  • NLP Classifiers: Emotion analysis and intent classification run locally using TensorFlow Lite
  • Voice Recognition: On-device speech-to-text using Android's SpeechRecognizer API or offline model
  • Cached models: AI models are cached locally for faster response times on repeated use
⚡

Performance Optimization

We've optimized Langou for a wide range of Android hardware:

  • Minimum requirements: Android 8.0 (API 26), 3GB RAM, 200MB storage
  • Recommended: Android 11+, 6GB RAM, Snapdragon 865 or equivalent
  • Battery impact: <2% additional battery usage per hour of typing
  • Memory footprint: ~80MB in active use, minimal background memory usage
  • Startup time: Cold start <500ms, warm start <200ms
🌙

Android-Specific Features

  • Material You: Dynamic theming support on Android 12+ — keyboard colors adapt to your wallpaper
  • Notification access: Optional — used to detect incoming chat notifications for proactive suggestions
  • Picture-in-picture: AI suggestion panel can appear as a small overlay even with keyboard dismissed
  • Shortcuts: Quick Settings tile to toggle AI mode, home screen widgets
  • Google Play compatibility: Available via direct APK download (Play Store integration planned)
