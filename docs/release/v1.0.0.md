# 懒狗输入法 v1.0.0

首个统一仓库正式版本。Android APK 与 Windows 一键安装 EXE 来自同一提交、同一标签，
并通过各自平台的正式签名门禁。

## Android

- Android 8.0 及以上
- 全拼、拼音 9 键、英文、数字、符号与 Emoji
- AI 默认开启；基于安全过滤后的聊天上下文生成最多三条回复建议
- 点击建议只写入输入框，不自动发送

## Windows

- Windows 10/11 x64
- 一键双击 EXE 安装
- TSF/RIME 输入核心与懒狗助手
- UIA 优先、OCR 降级的聊天上下文建议

## 安全与隐私

- 密码、支付、银行与系统安全页面禁止采集
- 截图只在本地内存中用于 OCR，不上传、不落盘
- 普通输入在断网和 AI 故障时仍可使用

正式公开前，Release 将保持 draft，直到 Android 真机、Windows 本机、24 小时 RC、
安装包签名、官网与 API 发布清单全部通过同一组哈希验收。
